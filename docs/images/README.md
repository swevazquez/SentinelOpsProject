# Documentation Images

This directory contains rendered images used by project documentation and reports.

- `project/`: Project-management and repository evidence.
- `reports/`: Burndown charts and other report-specific visuals.
- `ui/wireframes/`: PNG exports of editable UI wireframes from `docs/diagrams/ui/`.

Editable diagram sources belong under `docs/diagrams/`. Keep generated images here
only when they are needed for reports, reviews, or other rendered documentation.
