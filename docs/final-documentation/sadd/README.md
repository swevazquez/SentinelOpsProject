# Software Architecture and Design Documentation

The SentinelOps Software Architecture and Design Documentation explains how the implemented system is structured and why its major design choices were made.

## Document

- [Software Architecture and Design Documentation](software-architecture-and-design-draft.md)

## Content

The document covers:

- system goals, operational context, functional overview, and architectural drivers;
- constraints and non-functional requirements that influenced the design;
- high-level and low-level architecture views;
- FastAPI, Airflow, Spark, PostgreSQL, machine-learning, simulator, dashboard, and Assistant responsibilities;
- data-flow, deployment, package, schema, and interaction diagrams;
- mappings between architecture views and functional responsibilities; and
- design decisions, rationale, and trade-offs.

The described architecture matches the integrated Docker Compose deployment and the host-based development path included in the repository.
