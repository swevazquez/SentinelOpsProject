# SentinelOps Final Documentation

This directory contains the Markdown sources for the four final SentinelOps capstone documents. Each document reflects the integrated Sprint 4 implementation.

| Deliverable | Purpose | Markdown Source |
|---|---|---|
| Software Requirements Specification (SRS) | Defines the implemented functional and non-functional requirements and the significant algorithmic component. | [SRS](srs/software-requirements-specification-draft.md) |
| Software Architecture and Design Documentation (SADD) | Describes the system architecture, design views, component responsibilities, and major design decisions. | [SADD](sadd/software-architecture-and-design-draft.md) |
| Software Testing Report (STR) | Documents the test strategy, test cases, results, coverage, defects, and requirements traceability. | [STR](str/software-testing-report-draft.md) |
| Software End-User Manual (SEUD) | Provides maintenance-manager workflows and administrator installation, configuration, and deployment guidance. | [End-User Manual](sed/software-end-user-manual-draft.md) |

Supporting diagrams and screenshots are stored under `docs/images/final-documentation/` and the corresponding report image directories.

Markdown is the repository source of truth. PDF exports are generated locally under `output/pdf/` and are not tracked in Git.
