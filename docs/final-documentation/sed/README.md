# Software End-User Manual

The SentinelOps Software End-User Manual serves two audiences: maintenance managers using the application and administrators deploying or validating it.

## Document

- [Software End-User Manual](software-end-user-manual-draft.md)

## Maintenance-Manager Coverage

The manual explains how to:

- review fleet condition and maintenance priorities;
- search for assets and inspect prediction details;
- run the repeatable remaining-useful-life demonstration;
- review workflow history, results, and operational notifications;
- ask supported Assistant questions; and
- reject or approve a protected workflow action.

## Administrator Coverage

The manual also documents:

- supported tools, frameworks, APIs, and services;
- repository download and environment configuration;
- host-based and integrated Docker Compose deployment paths;
- Airflow, Spark, PostgreSQL, FastAPI, dashboard, and Assistant validation;
- demonstration-data preparation;
- API operations, testing commands, and troubleshooting; and
- screenshots captured from the delivered application and integrated service stack.
