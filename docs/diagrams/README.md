# Diagrams

This directory contains source diagrams and exported visuals used in the documentation.

## Directory Structure

- `architecture/`: System context, domain, component, and deployment diagrams.
- `workflows/`: Data processing, orchestration, and operational sequence diagrams.
- `ui/`: Low-fidelity interface wireframes used to guide frontend implementation.

Mermaid (`.mmd`) files are the editable source of truth for architecture and workflow
diagrams. Excalidraw (`.excalidraw`) files are the editable source of truth for UI
wireframes. Exported image files should remain beside their source diagram when an
image is required by a report, except UI wireframe exports, which are organized under
`docs/images/ui/wireframes/`.
